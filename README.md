## 🚀 Getting Started

### Prerequisites
- Node.js 18+ or higher
- npm, yarn, pnpm, or bun

### Installation

1. **Clone the repository**
   ```bash
   git clone https://github.com/arpit0381/code-hashira.git
   cd code-hashira
   ```

2. **Install dependencies**
   ```bash
   npm install
   # or
   yarn install
   # or
   pnpm install
   # or
   bun install
   ```

### Development

Start the development server:

```bash
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) with your browser to see the result.

The application will auto-reload as you edit files in `src/app/` or component files.

### Build

Create an optimized production build:

```bash
npm run build
```

### Start Production Server

Run the production build:

```bash
npm start
```

### Other Scripts

- **Lint**: Check code quality
  ```bash
  npm run lint
  ```

- **Extract Frames**: Extract animation frames (custom script)
  ```bash
  npm run extract-frames
  ```

## 🎨 Key Components & Features

### Animation System
The project leverages both GSAP and Framer Motion for sophisticated animations:
- **GSAP**: Timeline-based animations for complex sequences
- **Framer Motion**: React-native animation library for component transitions
- **Intersection Observer**: Trigger animations when elements enter the viewport

### Styling
- **Tailwind CSS 4**: Utility-first CSS for rapid UI development
- **CVA (Class Variance Authority)**: Type-safe component variants
- **Dynamic Classes**: Smart class merging with tailwind-merge

### State Management
- **Zustand**: Lightweight, fast state management without boilerplate
